# ⚡ Wizzy Collections

A modern, fully-responsive **e-commerce portfolio demo** built with React 19 and Vite. Showcasing UI/UX, component design, and front-end engineering skills — no backend required.

🔗 **Live Demo:** [wizzy-collections.vercel.app](https://wizzy-collections.vercel.app/)

---

## 📸 Preview

> A polished gadget store featuring phones, tablets, and laptops with animated product cards, a working cart drawer, wishlist, search, and more.

---

## ✨ Features

- **Animated Splash Screen** — cinematic entry with orb effects, scanline animation, and tech-tag chips
- **Responsive Layout** — fully adaptive across mobile (xs/sm), tablet (md), and desktop (lg) breakpoints
- **Product Catalog** — phones, tablets & laptops with badges, specs, ratings, and save-amount banners
- **Shopping Cart Drawer** — add, remove, and adjust quantities with live subtotal
- **Wishlist** — toggle heart on any product with toast feedback
- **Live Search** — real-time search across all products and brands
- **Animated Hero** — cycling word animation with gradient text
- **Category Grid** — clickable category cards that filter the product section
- **Testimonials & Features Strip** — social proof and trust badges
- **Promo Section** — full-bleed CTA with background imagery
- **Mobile Navigation** — hamburger menu with smooth slide-down animation
- **Toast Notifications** — lightweight action confirmations

## 🛠 Tech Stack

| Technology | Purpose |
|---|---|
| **React 19** | UI library with hooks (`useState`, `useEffect`, `useCallback`) |
| **Vite 8** | Lightning-fast dev server and bundler |
| **Inline CSS / CSS-in-JS** | All styles scoped inside components — zero CSS framework dependency |
| **Google Fonts** | Space Grotesk, Inter, JetBrains Mono |

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Wizzy67/wizzy-collections.git
cd wizzy-collections

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```
